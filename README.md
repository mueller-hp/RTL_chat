# RTL לצ'אט של Claude

## תוסף Chrome (claude.ai)
1. פתח chrome://extensions
2. הדלק "Developer mode" (מצב מפתח) בפינה הימנית העליונה
3. "Load unpacked" ובחר את התיקייה chrome-extension
4. רענן את claude.ai

## צ'אט באפליקציית Claude Desktop
1. סגור את Claude לגמרי, כולל האייקון ליד השעון
2. הפעל את desktop\Claude-RTL.cmd (אפשר ליצור לו קיצור דרך בשולחן העבודה)
3. Claude נפתח, וחלון קטן ממוזער בשם "Claude RTL" רץ לידו ונסגר לבד כש-Claude נסגר

צריך Node.js 22 ומעלה. אם Claude מותקן במקום אחר, הגדר משתנה סביבה CLAUDE_EXE עם הנתיב המלא ל-claude.exe.

## שימוש
- כפתור "עברית" בפינה הימנית התחתונה: הפעלה וכיבוי
- Ctrl+Alt+R: הפעלה וכיבוי
- Ctrl+Alt+H: הסתרת הכפתור או החזרתו

## חשוב לדעת
הקיצור פותח ב-Claude פורט דיבאג מקומי (127.0.0.1:9333). רק תוכנות שרצות על המחשב שלך יכולות להתחבר אליו, אבל כל תוכנה כזו יכולה לשלוט בחלון של Claude כל עוד הוא פתוח. אם זה מפריע, פתח את Claude מהקיצור הרגיל והתוסף פשוט לא יפעל.
